# 灯下 · 宫灯文献助手

**北京宫灯研究项目 / 衍生实验品 01 / 文献检索与交互原型**

[在线体验](https://sijian0202.github.io/palace-lantern-aigc/experiments/literature-assistant/app/) · [返回宫灯项目](../../README.md) · [衍生实验品索引](../README.md)

## 从文献整理中产生的需求

宫灯设计研究需要借鉴非遗数字化、元素提取、生成式设计和模型评价等方向的方法。逐篇阅读后形成的文献整理，仍然需要反复查找：哪些案例用过 LoRA、哪些研究评价了纹样生成效果、哪些设计方法可以借鉴到北京灯彩。

「灯下」将已有文献整理转为可交互的检索入口，支持以自然语言提出研究问题、查看相关文献卡片，并回到表格中的对应位置核对内容。

## 当前可以体验

- 检索38条文献记录，默认只检索其中32条标为项目相关的记录，可切换全部记录。
- 按主题、作者与词项匹配资料，例如“北京灯彩”“LoRA”“纹样评价”。
- 展示文献名称、作者、内容提取及匹配词项，点击卡片查看完整整理内容。
- 标注文献编号与原表格行号，区分内容提取与论文原文。
- 对资料不足的问题显示无匹配结果，支持新对话和复制检索说明。

可尝试的问题：

1. 哪些文献使用了 LoRA，并有具体的设计实践？
2. 北京灯彩相关研究采用了什么设计方法？
3. 哪些文献评价了 AI 生成纹样的效果？

## 实现与边界

当前公开版本为浏览器内的文献检索实验，使用 React、TypeScript 与词项/主题同义词加权匹配；不是向量检索，也没有调用大语言模型。生成式综合问答是后续探索方向，尚不将其表述为完成的 LLM API、RAG 或 Agent 应用。

公开数据包含文献名称、作者、内容提取与相关性标记，不包含个人阅读备注、论文全文、原始Excel、API密钥或用户问答记录。内容提取是二手整理，不替代原文核验，不提供论文页码或未经记录的实验参数。其他非遗案例仅用于方法借鉴，不直接作为北京宫灯的事实依据。

提问与检索均在浏览器内处理，不上传查询，不跨设备保存对话。刷新页面后恢复初始状态。若后续接入模型服务，将独立设置服务端密钥与调用接口，不把密钥放入公开网页。

## 与主项目的关系

该工具属于北京宫灯项目的研究辅助实验，展示文献组织、检索逻辑与交互原型实践。它不替代 LoRA 训练效果验证，也不作为产品转译成果的模型生成证明。

## 源码与复现

- `src/literature.json`：38条公开整理记录；个人阅读备注字段为空。
- `src/search.ts`：检索与相关性筛选。
- `src/App.tsx`：提问、结果卡片与依据详情。
- `app/`：可直接发布到 GitHub Pages 的构建产物。

在本目录安装依赖后运行 `npm run dev`，运行 `npm run build` 更新 `app/`。静态发布不需要服务器或API密钥。
